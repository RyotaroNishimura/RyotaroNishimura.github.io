## この人は何をするか

AI を使った業務自動化の仕組みづくりを、受託でお引き受けしています。

- 決まった時刻に数字を集め、判断して、知らせる。AI が下書きを作り、人が「OK」を返したあとに送る。データから、ページや資料をまとめて作る。この3つの型を、自社で毎日動かしている形のまま持っていきます
- 始める前に、どの業務のどの数字を動かすかと、人が確認する場所を決めます。1業務だけ動かして、実際に使われるかを見てから広げます
- 求人広告の法人営業、インフルエンサー施策の営業（[株式会社NexTrend](https://nextrend.tokyo)）を経て、いまは[株式会社REECH](https://corp.reech.co.jp/corporate)（クロス・マーケティンググループ）で SNS アカウントプランナーをしています。美容メーカー・食品メーカー・行政の PR を支援しています。業務の手順を聞き、どの数字が動けば成功かを決めてから作ります
- 勤務先では、Claude と Notion を社内に導入し、インフルエンサーのディレクションや営業の業務改善、AI でのクリエイティブ作成を進めています

## このリポジトリについて

- このリポジトリは、サイト https://ryotaronishimura.github.io のソースです
- [Astro](https://astro.build/) で静的なファイルに書き出し、GitHub Actions（`.github/workflows/deploy.yml`）で GitHub Pages に公開しています。`main` への push で公開されます
- 実装は AI エージェントに任せています。AI がやったのは、ページの実装、文章の下書き、画像の書き出し、ビルドと検査の実行です。人がやったのは、載せる物と載せない物を決めること、数字を一次ソースで確かめること、公開してよいかを決めることです
- 判断の記録は日付つきでサイトに載せています（[このサイトの作り方](https://ryotaronishimura.github.io/process/)）
- 数字・氏名・連絡先・本文は `src/config/` のファイルにまとめてあり、ページ側はそこから読みます。この README と `docs/` も同じファイルから写しています
