# なぜ営業出身が組むのか

最終更新: 2026-10-13

## AI 導入がつまずくのは、たいてい技術の手前です。

つまずく原因の多くは、どの業務の何の数字を動かすのかを、作る前に誰も決めていないことです。エンジニアではなく、営業の現場を知る人間が組む理由はここにあります。

## よくある進め方と、このやり方の違い

| 項目 | よくある進め方 | このやり方 |
| --- | --- | --- |
| 始め方 | 「AI で何かやろう」と、道具から入る | どの業務の、どの数字を動かすかから入る |
| 目標 | 動いたかどうかしか見ない | 始める前に「何がどうなったら成功か」を数字で決める |
| 範囲 | 全部の業務を一度に置き換えようとする | 1業務だけ動かして、実際に使われるかを見る |
| 人の役割 | 人を外すこと自体が目的になる | 人が確認する場所を先に決めて、そこだけは人に残す |
| 組む人 | 業務を知らない人が、聞いたとおりに作る | 現場の手順と数字を、自分で聞き取れる人が組む |

## 営業でやってきたことと、同じ順番で作る

求人広告の営業では、初めて伺う会社の事業と稼ぎ方を先に調べ、仮説を持って話を聞いてきました。提案を通すには、相手の担当者が追っている目標の数字に合わせる必要があります。AI の仕組みづくりでも、最初にやることは同じです。業務の手順を聞き、どの数字が動けば成功かを決めてから作ります。

いまの勤務先の[株式会社REECH](https://corp.reech.co.jp/corporate)では、Claude と Notion を社内に導入し、インフルエンサーのディレクションや営業の業務改善、AI でのクリエイティブ作成を進めています。現場の業務を知る側が AI を組む、という形を勤務先でも続けています。

営業時代の数字といまの仕事は [経歴](03_経歴.md) にまとめています。
