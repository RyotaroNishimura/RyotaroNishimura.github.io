# よくある質問

最終更新: 2026-10-12

## エンジニアではないのに、作れるのですか。

コードを書く作業は AI エージェントに任せています。サイトに載せている自社の仕組みも、全部そのやり方で作って動かしています。

私の仕事は、その手前と後ろです。どの業務のどの数字を動かすかを決めること、人が確認する場所を決めること、出てきた物が事実どおりに動いているかを確かめること。ここは業務を知らないと決められません。

## 受託の実績はありますか。

受託の実績は、まだありません。だからこそ最初の数社は、私が直接、最後まで担当します。お見せできるのは、自社で毎日動かしている仕組みそのものです。

そのため、サイトとこのリポジトリでは自社で運用中の実例だけを、時点をつけて載せています（[自社で運用中の実例](02_自社で運用中の実例.md)）。受託の実績ができたら、許可をいただいた範囲で足します。

## どんな道具を使いますか。

業務と、いま社内で使っている道具に合わせて選びます。新しい道具を入れること自体を目的にはしません。

自社では、AI エージェント（Claude Code など）、決まった時刻に処理を動かす仕組み、通知と承認に使う Discord、画面を操作するブラウザを組み合わせています。

## 費用はどのくらいかかりますか。

金額は、ご相談の内容をうかがったうえで、書面のお見積りでお出しします。サイトには料金を載せていません。

範囲を先に決めてから金額を出すので、「作ってみたら想定の何倍もかかった」を起こしにくくしています。

## 社内のデータを、外の AI に渡したくありません。

何を AI に渡して、何を渡さないかは、作り始める前に書面で決めます。渡さない前提で組める業務もあります。

個人情報や社外秘のデータを、取り決めをしないまま外部の AI サービスに渡す作り方はしません。

## 業務を全部、自動化できますか。

全部はお約束しません。自社でも、外に出るもの（X の投稿など）は人が「OK」を返してから出ています。

最初に1業務だけ動かし、使われると分かった所から広げます。人が判断したほうがよい場所は、人に残す設計にします。
