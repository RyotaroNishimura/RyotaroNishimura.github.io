# 今できること

最終更新: 2026-10-25

営業とプランニングを軸に、いまできることは次の3つです。数字と時期の出典は [経歴](03_経歴.md) にまとめています。

## 1. 営業・提案

無形商材（求人広告）から SaaS まで、新規開拓と、既存のお客様の深耕の両方をやってきました。初めて伺う会社は、事業と稼ぎ方を調べて仮説を持ってから話を聞き、相手の担当者が追っている数字に合わせて提案を組み立てます。

- **経験**: 求人広告の法人営業（2021年8月〜2024年5月）、インフルエンサー施策の営業（2024年6月〜2025年6月）、SaaS（[REECH DATABASE](https://reech.co.jp/)）の法人営業（現職）

## 2. プランニング

インフルエンサーと広告を組み合わせた SNS 施策・PR を企画します。ミドルインフルエンサー施策や認知拡大から、購買につながる口コミづくりまでを設計します。

- **経験**: 株式会社REECH の SNS アカウントプランナーとして、美容メーカー・食品メーカー・行政の PR 支援を担当（2026年10月時点）

## 3. AI 活用

勤務先では、全社への AI 導入を推進しています。ツールの比較から、社内オリエンテーション、定着させるためのチェックまで取り組んでいます。個人でも、AI エージェントと一緒にアプリや毎朝動く仕組みを作り、自分の仕事に使っています。

- **経験**: 勤務先での取り組みは [経歴](03_経歴.md) の「社内の AI 推進」に、個人で作った物は [AI で作っているもの](02_AIで作っているもの.md) と [つくったもの](04_つくったもの.md) にまとめています
